6. Spring Security
  - Core Architecture & Filter Chain Internals
    - DelegatingFilterProxy & FilterChainProxy
    - SecurityFilterChain architecture & default filter ordering (from ChannelProcessingFilter to FilterSecurityInterceptor/AuthorizationFilter)
    - Security Context Model: SecurityContextHolder, SecurityContext, Authentication (Principal, Credentials, Authorities)
    - ThreadLocal storage mechanism & SecurityContextHolder strategies (MODE_THREADLOCAL, MODE_INHERITABLETHREADLOCAL)
    - Authentication Flow: AuthenticationManager, ProviderManager, AuthenticationProvider & UserDetailsService
    - Authorization Model: Modern AuthorizationManager (replacing legacy AccessDecisionManager), RequestMatcherDelegatingAuthorizationManager
  - Authentication Mechanisms
    - Username/Password Authentication (DaoAuthenticationProvider, PasswordEncoder: BCrypt, Argon2, SCrypt)
    - Session-based Authentication vs Stateless Token-based Architecture
    - JWT (JSON Web Token) Deep Dive:
      - Anatomy (Header, Claims/Payload, Signature), Symmetric (HMAC) vs Asymmetric (RSA/ECDSA) Signing
      - Custom OncePerRequestFilter for JWT parsing and SecurityContext populating
      - Dual-Token Architecture: Short-lived Access Token & Long-lived Refresh Token
      - Refresh Token Rotation (RTR) & Token Family Tracking to detect token theft
      - Instant Token Revocation & Blacklisting strategies (Redis TTL, JTI blacklist)
      - Custom AuthenticationEntryPoint (401 Unauthorized) & AccessDeniedHandler (403 Forbidden) JSON responses
  - Authorization & Access Control (RBAC & ABAC)
    - URL-level Authorization: requestMatchers(), hasRole vs hasAuthority, permitAll, authenticated
    - Method-level Security: @EnableMethodSecurity, @PreAuthorize, @PostAuthorize, @PreFilter, @PostFilter
    - SpEL (Spring Expression Language) security expressions
    - Custom PermissionEvaluator for Object-level and Domain-level security
    - Attribute-Based Access Control (ABAC) using custom AuthorizationManager<RequestAuthorizationContext>
  - OAuth 2.0 & OpenID Connect (OIDC) - Modern OAuth 2.1
    - OAuth 2.0 vs OIDC: Roles (Resource Owner, Client, Authorization Server, Resource Server)
    - OAuth 2.1 Specification: Why Implicit Grant & Resource Owner Password Credentials (ROPC) are deprecated
    - Authorization Code Flow with PKCE (Proof Key for Code Exchange)
    - Client Credentials Flow for Machine-to-Machine (M2M) communication
    - Spring Security OAuth2 Resource Server: Nimbus JOSE + JWT decoder, JWKS uri endpoint validation
    - Spring Security OAuth2 Client: Social Login (Google, GitHub, Keycloak, Auth0) & Token Relay
    - Spring Authorization Server: Designing and hosting a dedicated Identity Provider (IdP)
  - Application Hardening & Web Defenses
    - CSRF (Cross-Site Request Forgery): Mechanics, CookieCsrfTokenRepository, SPA integration, and why stateless APIs disable CSRF
    - CORS (Cross-Origin Resource Sharing): Preflight OPTIONS requests, CorsConfigurationSource, Allowed Origins vs Wildcard traps
    - Security HTTP Response Headers (HSTS, Content Security Policy - CSP, X-Frame-Options, X-Content-Type-Options)
    - Protection against Brute-Force & Credential Stuffing: Rate limiting (Bucket4j), failed attempt counters, Account Locking
    - Sensitive Data Masking & Secure Password Storage
  - Advanced Security Engineering & Production Mastery
    - SecurityContext propagation with Virtual Threads (Project Loom) & Asynchronous tasks (@Async, TaskDecorator)
    - Multi-Factor Authentication (MFA / 2FA with TOTP - RFC 6238, Google Authenticator)
    - Multi-Tenant Security: Tenant-aware SecurityContext and Dynamic Tenant-specific UserDetailsService/Keycloak realms
    - Zero Trust Architecture: Mutual TLS (mTLS) between microservices
  - Modern Spring Boot Integration
    - Spring Boot 4.1.0 & Spring Framework 7.0.8 / Spring Security 7.x Functional Lambda DSL (http.authorizeHttpRequests(...))
    - Complete removal of WebSecurityConfigurerAdapter & modern component-based configuration
